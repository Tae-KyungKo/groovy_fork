# 15. 주석 정리 (legacy-monolith 등 죽은 참조)

**날짜**: 2026-08-19
**분석 결과 원문 항목**: 종합 분석 🟡 (tempo.yaml/datasource.yml 등 이미 사실이 아닌 주석)

## 확인 범위와 판단 기준

저장소 전체(`backend/`, `docker-compose.*.yml`, `monitoring-msa/`)에서 "legacy-monolith"를
재검색해 남은 언급을 전부 검토했다. 판단 기준은 하나 — **"legacy-monolith가 삭제됐다/옮겨왔다"는
과거형으로 정확히 서술하는 주석은 그대로 두고, "현재도 legacy-monolith가 존재하거나 관련이
있는 것처럼" 오해를 주는 주석만 고친다.**

## 고친 것

1. **`study-service/application.yml:43`**: "notification-service/legacy-monolith와 동일한
   패턴"이라는 비교 주석 → "calendar/content/notification-service와 동일한 패턴"으로 변경.
   7번 작업으로 notification-service도 identity-service를 가리키게 됐으니, 이제 4개 서비스
   모두를 정확히 비교 대상으로 언급하는 게 맞다.
2. **`monitoring-msa/tempo/tempo.yaml:3-4`**: "이 검증 스택엔 Prometheus가 없음"이라는 주석 →
   실제로는 같은 스택에 Prometheus가 있고(`docker-compose.local.yml`의 `prometheus` 서비스,
   바로 옆 `datasource.yml`에도 Prometheus datasource가 정의돼 있음) 메트릭 수집 자체는
   Prometheus가 각 서비스를 직접 스크레이프하는 방식으로 이미 하고 있어서 Tempo의
   metrics_generator가 필요 없다는 실제 이유로 정정.
3. **`monitoring-msa/grafana/provisioning/datasources/datasource.yml:1-3`**: "원본 파일은
   실제 운영 docker-compose.yml이 쓰고 있어 건드리지 않는다"는 주석 → 레거시 `monitoring/`
   디렉토리는 MSA 전환 후 완전히 삭제되어 이 파일이 유일한 datasource 설정이라는 현재
   사실로 정정.

## 그대로 둔 것 (정확한 과거형 서술)

- `api-gateway/application.yml:10`, `docker-compose.local.yml:25,114`,
  `docker-compose.example.yml:18,107` — 전부 "legacy-monolith는 삭제됐다"/"~와 함께 없앴다"는
  정확한 과거형 서술.
- `identity-service`의 `JwksController.java`/`JwtKeyProvider.java`/`TokenProvider.java` —
  "groovy(legacy-monolith)의 X를 그대로 옮겨왔다"는 코드 출처(provenance) 설명. 코드가
  어디서 왔는지는 시간이 지나도 변하지 않는 사실이라 계속 정확하다.
- `study-service/test/.../TagPreferenceClientContractTest.java:17` — "이제 legacy-monolith가
  아니라 identity-service를 호출한다"는 마이그레이션 전후 대비 설명. "이제"로 현재와
  과거를 정확히 구분하고 있어 문제없음.

## 검증

- 변경한 YAML 3개 파일(`study-service/application.yml`, `tempo.yaml`, `datasource.yml`)
  전부 `python3 -c "import yaml; yaml.safe_load(...)"`로 문법 확인.
- `./gradlew build -x bootJar --continue`(전체 모듈) — notification-service의
  `contextLoads()`(Redis 미기동, 기존부터의 무관한 실패) 하나만 빼고 전부 성공.
- 저장소 전체에서 "legacy-monolith" 재검색 결과, 남은 언급은 전부 정확한 과거형 서술임을
  확인.
